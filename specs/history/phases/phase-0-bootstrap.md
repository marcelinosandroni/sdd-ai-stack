# ✅ Phase 0 — Bootstrap (DONE)

> **Scope:** the core restructure.
> **Status:** superseded by [phase-1-english.md](./phase-1-english.md) for the parts

---

## 🧭 What it was

- A stack focused on **React (Vite) + Node.js** (a `client/` + `server/` monorepo)
- No project template
- No Next.js rules
- No CLI / npm package
- Rules scattered across the root
- A generic design system (the default Vercel/Linear look)

## 🧭 What it became

| Before | After |
| --- | --- |
| React + Vite as the default | **Next.js 16 (App Router)** as the default |
| A generic `NODE.md` | `stacks/node.md` as a **complement** (worker/cron/queue) |
| `REACT.md` as the frontend doc | `stacks/react.md` as a **complement** (Server-First) |
| — | **`stacks/next.md`** with 11 rule sections |
| Rules scattered in the root | **`stacks/`** (typescript, tailwind, shadcn, testing, database, ai, git, ci) |
| A generic `DESIGN.md` | **`DESIGN.md`** Executive Engineering, tokens and all |
| — | **`APP-STACK.md`** (the stack pointer) |
| — | **`template/next/`** — a complete, tested Next.js 16 app |
| — | **npm CLI `create-sdd-ai-stack`** |
| — | **SKILL `install-submodule`** for an existing project |
| — | **SKILL `check-docs`** |

## 🐛 Real bugs found and fixed during validation

Validating the template for real caught 8 defects that would only have surfaced for
whoever installed it:

1. `error.tsx` without `"use client"` — the build broke
2. `reactCompiler: true` without `babel-plugin-react-compiler` installed — the build broke
3. `biome.json` on the 1.x schema — lint broke on Biome 2
4. `prepare: "husky || true"` — `npm install` broke on Windows
5. `proxy.ts` redirecting `/` and hiding the landing page — caught by E2E
6. The `/` route duplicated between `app/page.tsx` and `(marketing)/page.tsx` — caught by
   E2E
7. An `import type` from the wrong file in the example slice — caught by typecheck
8. `installShortcuts` returning `undefined` in stub mode

> That is exactly why the "proof of life, anti-hallucination" rule exists in
> `AGENTS.md`.
